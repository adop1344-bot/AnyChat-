# AnyChat+

Форк [AnyChat](https://github.com/internetovoder/AnyChat) — Android-приложение
(Flutter) для общения с LLM через **ваш API-ключ**: свой ChatGPT на Material 3 —
SSE-стриминг, Markdown-ответы, ветвление диалога, контроль контекста,
вложения, локализация ru / en / uk.

Форк живёт параллельно с оригиналом (`com.anychat.fork`) и добавляет то, чего
не хватает в апстриме.

## Отличия от апстрима

**Навигация и UI**
- Новый выбор модели: bottom sheet с поиском, бейджами мультимодальности,
  избранным и фильтрами по провайдерам
- Health-бейджи провайдеров прямо в списке
- Лист вложений с лентой фото, камерой и выбором файлов (вместо одного интента)
- Полиш Material You, пустое состояние с подсказками, настройка кеширования промптов
- Новая иконка-искра (адаптивная)

**Проверка моделей**
- Кнопка проверки в экране моделей: параллельно опрашивает все модели провайдера
  минимальным запросом; рабочие получают ✓, битые ✗ и красную обводку — сразу
  видно, какие ID живые

**Фиксы**
- `max_tokens` на reasoning-моделях (резерв под рассуждения)
- Пустой контент Anthropic и reasoning-only стримы больше не роняют чат
- Креш `Map<String,String>` в точках восстановления кеша

**Инфраструктура**
- CI: каждый пуш в main собирает APK и публикует в Releases
  (`build-latest`), тег `v*` — полноценный релиз

## Установка

Сборки публикуются в **Releases**: свежая — `AnyChat+-build-latest.apk`,
стабильные — под тегами `v*`.

Требования: Android 7.0+, интернет или локальный Ollama.

Все сборки (CI и локальные) подписаны одним debug-ключом — обновления
ставятся поверх без удаления.

## Быстрый старт

1. **Гамбургер → Настройки → Провайдер → «+»**: название, эндпоинт
   (например `https://api.openai.com/v1`), формат (`openai` у большинства
   шлюзов; `anthropic` / `gemini` — нативные API) и API-ключ (в UI видна
   только маска).
2. В меню провайдера — **Проверить ключ**: минимальный chat-проба;
   при ошибке показывается её причина.
3. **Настройки → Модели**: выбор модели (поиск, цена за 1M токенов,
   контекст, бейджи мультимодальности) либо ввод своего ID вручную.
4. Пишите в чат. Drawer: переименование чата, его системный промпт,
   **Сжать историю**, удаление; внизу — «Новый чат» и Настройки.
   Ветвление: правка сообщения создаёт ветку, «Ветка отсюда» — откат.

## Параметры

| Где | Параметр | Что делает |
|-----|----------|------------|
| Генерация | `max_tokens`, таймаут, системный промпт | ограничения запроса; системный промпт есть и глобальный, и по-чатовый |
| Расширенные | `reasoning_effort` | уровни берутся от модели; по умолчанию «Не отправлять» |
| Расширенные | лимит контекста, глубина истории | индикатор контекста и срез последних N сообщений перед отправкой |

Настроек temperature / top_p нет — используются дефолты провайдера.

## Ограничения

- Только Android; нет iOS / web / desktop.
- Нет подсветки синтаксиса кода — код-блоки моноширинные, без цветов.
- Нет tool calling и генерации изображений; вложения — только готовые
  файлы (без записи с микрофона).
- Нет экспорта чатов и поиска по истории.
- Индикатор контекста — приблизительная оценка, точного подсчёта токенов нет.
